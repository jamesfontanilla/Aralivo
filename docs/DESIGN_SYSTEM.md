# Study clay design system

The visual language uses soft depth selectively: rounded tactile surfaces for actions and progress, quieter reading/settings/data surfaces, visible borders, and no shadow-only state changes.

## Tokens

Canvas `#eeeafb`, surface `#fbfaff`, ink `#29233e`, muted `#615b78`, primary `#8374f1`, strong primary `#5142b7`, mint `#8fd9c6`, coral `#e48d84`, yellow `#eabf62`, border `#cfc7e7`.

Headings and friendly controls use Nunito; body and dense UI use DM Sans. Controls use 12–16px radius, standard cards 18–24px, and reading surfaces stay restrained.

## Accessibility

Visible focus, semantic headings, skip links, labels, keyboard-friendly controls, status messages, 44px targets, reduced motion, forced-colors support, and responsive layouts are required. Color is never the only status signal. Test at 320px–1440px widths and 200% zoom.

## Reference decisions

Course → unit → lesson → practice hierarchy and visible mastery/progress cues were inspired by public Khan Academy patterns. Claymorphism was adapted with contrast and motion safeguards informed by Smashing Magazine. Settings follow grouped SaaS patterns with separate profile/security/privacy/danger sections.

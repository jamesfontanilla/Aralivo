# Public implementation references

The product hierarchy and practice handoff were informed by public Khan Academy course/lesson/practice patterns. Claymorphism was used as a visual direction with contrast and reduced-motion safeguards. Settings grouping follows public SaaS account-settings patterns.

Provider behavior was checked against current public documentation for Supabase Google OAuth, Brevo transactional email, Google Calendar quotas, Vercel FastAPI functions, Stellar/Soroban smart contracts, Open Library usage guidelines, and OpenAlex API access. Optional Nager Holidays and Open-Meteo adapters remain isolated and non-core.
